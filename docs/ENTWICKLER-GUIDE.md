# Entwickler-Guide

Dieser Guide hilft bei der Weiterentwicklung von `syncdb2`.

## Build

```bash
mvn clean install
```

## Tests

Alle Module enthalten JUnit-Tests mit AssertJ. Führen Sie sie mit `mvn test` aus.

## Richtlinien

- Kommentare und Dokumentation in deutscher Sprache.
- Neue Module sollten eine `ARCHITEKTUR.md` enthalten.
